# 检验清单（方法论卡 M01–M12）

每张卡：一句话主张 + 供解读时逐条追问的检验问题。引用时标卡片编号，如 [M02]。所有卡的状态：出处已核对；有效性未验证。主张是对他公开文字的转述，来源编号见 `sources.md`。

## M01 目标函数：不败而求胜

主张：他把"在最极端场景下仍能活着"放在"赚多少"之前，并为此主动牺牲收益：固定净多、分散、衍生品保护、把大部分配置放在"守正"。

检验问题：

1. 在 2008/2011/2020 式的极端场景下，这笔仓位或这个组合还能活下来吗？活下来依赖什么（流动性、杠杆、对手方、赎回条款）？
2. 这笔属于守正还是出奇？出奇部分合计是否仍在自己预设的上限内？
3. 是否在为了让短期曲线好看，回避本该承担的亏损？

## M02 价值定义：同业效率差 × 存续时间

主张：价值不是资产折价，而是"比同行更高效"以及"这个差距能维持多久"；追踪的对象是效率变化，不是产品价格变化。平庸企业没有价值。

检验问题：

1. 效率差具体是什么（成本、毛利、周转、资本成本、转化率）？与谁比？有没有数？
2. 存续多久：靠什么维持（规模、技术、物理半径、行政门槛）？
3. 差距在扩大还是收窄：看市占率、毛利率差、同行对比，而不是看产品价格。
4. 这是不是"便宜的二流"：同行业里有没有更贵但更好的一流？
5. 当前上涨或下跌，是周期（价格）还是效率变化？

## M03 赔率：边际、前景、估值三要素

主张：决策的唯一标准是赔率；赔率由边际、前景、估值共同构成。估值提供赔率，大部分时候不决定方向；估值回升是礼物，不是买入理由。

检验问题：

1. 赔率三要素各自是什么：边际（下一两个季度的变化）、前景（空间多大、多久）、估值（对应什么现金流预期）？
2. 如果估值永远不回升，持有回报是否仍可接受？（S34 的追问：不回归能不能接受）
3. 这是几分的机会？有没有更高分的机会正在被占用的资金挡住？
4. 当前是低估值还是高估值语境，S17 与 S24 哪一条适用？

## M04 估值底线：绝对估值优先，机会成本即贴现率

主张：先满足绝对估值，再看相对估值；贴现率不是随手选的 3%，而是手里最好的替代品能给的回报；更关心"市场先生不报价，多久能收回投资"。

检验问题：

1. 最悲观假设下，绝对估值的下限在哪里？现金流回收期多少年？
2. 手里最好的替代品给多少回报？这个标的的预期回报是否胜过它？
3. 市场长期不报价，几年能收回投资？
4. 现金流是否被利息、资本开支、承诺性支出吃掉（SOHO 型）？
5. 高息是否可持续：派息比例、大股东行为、回购意愿，流动性是否允许需要时变现？

## M05 现金流、股东回报与管理层

主张：估值方法可以换，对企业现金流的预判不能换；现金流之后看的是钱怎么花、怎么回报股东，以及管理层说话是否算数。99% 的场景里，管理层最重要。

检验问题：

1. 近几年自由现金流和净利润的关系；现金流能否被利息、资本开支、承诺性支出吃掉？
2. 钱怎么花：并购、扩张、回购、分红，历史记录是"乱投资"还是持续回报股东？
3. 管理层过去的承诺和指引是否兑现？有没有"来不及转账"这类失信？
4. 大股东行为：增发、私有化价格、关联交易、增减持。
5. 现金的真实性：账上现金能否被独立验证？
6. 行业格局：这个行业属于天然形成垄断、天然拥有健康现金流的类型，还是一场一场战役、一笔接一笔回款的百战之地？这决定现金流是否可持续。

## M06 防雷清单：老千、烟蒂、政策、泡沫杠杆、行政垄断

主张：这是他在亏损里反复付过学费的几类地雷：老千股与半千股、没有催化剂的烟蒂、政策单点风险、泡沫资产上加杠杆的商业模式、靠行政门槛维持的垄断。每一类都有他自己的案例。

检验问题：

1. 有没有半千股的特征：高位增发低位私有化、关联交易、业绩调节、家族深度参与？
2. 如果是烟蒂：催化剂是什么？时间窗口多长？管理层是否可信？流动性允许止损吗？
3. 它的护城河靠的是行政门槛还是真实效率？政策放松后还成立吗？
4. 它依赖的底层资产是否处于泡沫？有没有在这类资产上加杠杆？
5. 政策是单点风险吗？不预测的前提下，能否用对冲或仓位上限消化？
6. 跟踪成本和能得到的信息，是否撑得起一个有信心的判断？

## M07 变化导向：边际与增量、为什么是此时此刻

主张：他的工作不是解释股价，而是找"改变均衡的增量"；检验方法是把理由放到别的时点，仍成立的是存量，只在此时此刻成立的才是增量；新生意模式出现时一定问"为什么是现在"。

检验问题：

1. 现在这条理由，放到半年前或一年前也成立吗？成立则是存量。
2. 这个变化有物理层面的原因吗？为什么不是三年前、也不是三年后？
3. 价格里已经反映了什么？对方（多空双方）真正恐惧的是什么？
4. 我是否真的研究过相反的一面，而不只是口头换位？
5. 这是效率和现金流层面的变化，还是销量和价格层面的短期波动？

## M08 能力圈与外扩纪律

主张：看不懂的钱不赚；复盘看不出过去为什么涨跌的，不参与；新行业先看一轮产业周期再决定；跨出能力圈要更慎重并留足安全边际。

检验问题：

1. 能否复盘它过去几年为什么涨、为什么跌？如果不能，先别参与。
2. 我（使用者）在这个行业或市场里有持续跟踪吗？还是第一次碰？
3. 这个标的我能获得的信息优势在哪？跟踪成本是否可接受？
4. 如果是新行业，是否已经看过至少一轮产业周期？还是只看了景气度？
5. 我正在回答的问题，是否本质上是宏观、政策、疫情这类能力圈以外的预测？

## M09 组合结构、仓位带与容量

主张：用"双袋"（成长股对冲、高息价值股不对冲）加"4 行业 × 3 市场 × 3 风格"降低关联；净多长期在 50% 附近，实际在 58–65% 间；规模变大后更追求确定性和流动性，集中度上升，空头改用篮子。

检验问题：

1. 这个标的会占组合的多少？与已有持仓是否在同一风险因子（行业、市场、风格）上？
2. 它属于哪个"袋"：需要对冲的成长，还是不对冲的高息？它的流动性能否在需要时变现再平衡？
3. 若极端情景下它同时下跌，组合的关联度是否真的低？
4. 关键时刻有没有现金或余地？

## M10 对冲与做空纪律

主张：对冲的目的是绕开自己无法判断的问题，不是赚空头的钱；空头亏损无限，所以小仓位、硬止损、只空自己曾理解其上涨的，不做泡沫的对手；泡沫阶段宁可丢多头，也不冒失对冲。

检验问题：

1. 要对冲的是哪个自己无法判断的问题？对冲的工具与被保护的头寸是否同一风险因子？
2. 如果做空：我是否曾经理解它的上涨？空头仓位上限？硬止损在哪？亏损无限的情景我扛得住吗？
3. 空头目的是控制风险还是想赚钱？如果是后者，赔率天然更差，要有额外理由。
4. 当前是否处在泡沫阶段？同行业配对会不会因流动性溢出而被二三线反超？
5. 空头金额变大时，是否改用篮子或指数？

## M11 左侧交易、加仓上限与退出

主张：他是左侧选手，会在好公司下跌时加仓，但必须有左侧仓位上限和分散，"我们不是无限弹药"；对好公司不按价格止损，退出的触发源是"逻辑破灭或失控"，不是价格。

检验问题：

1. 如果下跌，我加仓的依据是价值判断还是成本摊薄？（S01：沉没成本不是理由）
2. 左侧仓位上限是多少？是否已经写下来？分散到几个互不相关的风险上？
3. 我退出的条件是什么？是"逻辑破灭""失控""行业被取缔"中的哪一种？价格是否也被写成了触发？
4. 它是成长、周期、概念、烟蒂中的哪一类？时机应该选左侧还是右侧？
5. 如果我正处在"被屁股绑架"的状态，我是否还能给出客观判断？
